# Ocean Activities and Sectors Map for the CCLME

## Part of WCOA's Cumulative Impact Assessment Needs Inventory Project

This is a temporary repository to host an interactive HTML map of ocean activities and sectors within the California Current LME.

**Please note that this is a temporary repository for the map files to allow for interactive access to the map during an August 13th Workshop; the final hosting location for this map is to be determined.**
